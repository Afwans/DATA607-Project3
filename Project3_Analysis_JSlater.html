Value Proxy 1: Demand

n_jobs <- nrow(jobs)

wilson <- function(x, n, z = 1.96) {
  p <- x / n
  centre <- (p + z^2 / (2 * n)) / (1 + z^2 / n)
  half   <- z * sqrt(p * (1 - p) / n + z^2 / (4 * n^2)) / (1 + z^2 / n)
  tibble(lo = centre - half, hi = centre + half)
}

demand <- skills %>%
  count(skill_name,name = "postings") %>%
  mutate(share = postings / n_jobs) %>%
  bind_cols(wilson(.$postings, n_jobs)) %>%
  arrange(desc(share)) %>%
  mutate(demand_rank = row_number())

write_csv(demand, "Data/Analysis/skill_demand.csv")

Each role has its own profile:

  • AI/ML postings are associated with Python, Machine Learning, LLMs and PyTorch. SQL appears in only 7% of them, far less than in any other category.
  • Data Analytics and Business Intelligence rely most on SQL plus a BI tool (Tableau, Power BI), with dbt appearing in about a quarter of analytics postings.

Data Science and AI/ML postings pay the most, Data Analytics and BI the least

  • Skill premium: median salary of postings that mention the skill minus the median of postings that do not, with a 95% bootstrap confidence interval.

Small categories are merged for modeling (Business Intelligence → Data Analytics; Database → Data Engineering; Statistics → Data Science), and only skills mentioned in at least 10 salaried postings are estimated.

set.seed(607)

pay_model <- pay %>%
  mutate(cat_model = fct_collapse(as.character(job_category),
                                  "Data Analytics"   = c("Data Analytics", "Business Intelligence"),
                                  "Data Engineering" = c("Data Engineering", "Database"),
                                  "Data Science"     = c("Data Science", "Statistics")) %>%
           fct_relevel("Data Analytics"),
         log_salary = log(salary_midpoint_annual))

pay_skills <- skills %>% filter(job_id %in% pay_model$job_id)
eligible <- count(pay_skills, skill_name) %>% filter(n >= 10) %>% pull(skill_name)

boot_median_diff <- function(y, x, reps = 2000) {
  est <- median(y[x]) - median(y[!x])
  b <- replicate(reps, {
    i <- sample(length(y), replace = TRUE)
    yy <- y[i]; xx <- x[i]
    median(yy[xx]) - median(yy[!xx])
  })
  tibble(raw = est, raw_lo = quantile(b, 0.025, na.rm = TRUE),
         raw_hi = quantile(b, 0.975, na.rm = TRUE))
}

premiums <- map_dfr(eligible, function(s) {
  d <- pay_model %>% mutate(has = job_id %in% pay_skills$job_id[pay_skills$skill_name == s])
  fit <- lm(log_salary ~ has + cat_model, data = d)
  co  <- tidy(fit, conf.int = TRUE) %>% filter(term == "hasTRUE")
  bind_cols(
    tibble(skill_name = s, n_with = sum(d$has)),
    boot_median_diff(d$salary_midpoint_annual, d$has),
    tibble(adj = exp(co$estimate) - 1, adj_lo = exp(co$conf.low) - 1,
           adj_hi = exp(co$conf.high) - 1, adj_p = co$p.value)
  )
}) %>%
  left_join(select(demand, skill_name,share), by = "skill_name") %>%
  arrange(desc(adj))

write_csv(premiums, "Data/Analysis/skill_salary_premiums.csv")
order_lvls <- premiums$skill_name[order(premiums$adj)]

Findings:

  • Raw gaps are large and mostly reflect the job type. Machine Learning, LLM and PyTorch postings advertise about $28K–$38K more than other postings. Excel, Power BI, Tableau and Data Visualization postings advertise $50K–$68K less.
  • SQL shows a penalty of $40K, only because the highest-paying category (AI/ML) rarely lists SQL.
  • Excel, Data Visualization and Power BI stay lower even within the same job category: Excel by 26%, Data Visualization by 23% and Power BI by 18%. These are the only statistically significant estimates (p < 0.05). Postings that emphasize spreadsheets and visualization tend to be reporting-focused roles, which pay less than the rest of their category.
  • With 178 salaried postings, most confidence intervals include zero.

Answer to the research question

There is no single “most valued” skill. The proxies (demand, pay) agree on some skills and disagree on others:

  1. Foundational skills: Python and SQL are the most valued skills by demand and reach.
  2. Machine Learning is the best all-round skill. Statistics follows
  3. BI and spreadsheet skills are in demand but not well paid. Tableau, Power BI

Limitations and future work

  • Representativeness. The postings come from companies that use specific applicant-tracking systems and are concentrated in the US and in tech.
  • Small analytical sample. The data-role analysis rests on 226 postings (178 with usable salaries).
  • Measurement. Keyword extraction cannot distinguish required from preferred skills or detect proficiency.
  • Advertised, not realized, pay.
  • Don’t take into account seniority
  • No longitudinal analysis
  • No supply and demand comparison. Did not integrate CV or resume data.
